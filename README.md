# Vision Forge React

Landing page em React e Vite para a apresentação do projeto Vision Forge.

## Tecnologias

- React 18
- Vite
- JavaScript
- CSS

## Requisitos

- Node.js 18.18 ou superior
- npm

## Instalação

```bash
npm install
```

## Execução

```bash
npm start
```

Se preferir, também funciona com:

```bash
npm run dev
```

## Build de produção

```bash
npm run build
```

## Pré-visualização do build

```bash
npm run preview
```

## Status de autenticação

Não há autenticação nesta entrega. O projeto é uma landing page estática.

IA utilizada como apoio na organização da documentação e na revisão do material entregue. O conteúdo final foi ajustado para refletir os arquivos presentes neste repositório.
